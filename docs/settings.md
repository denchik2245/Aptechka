# Настройки прототипа

Настройки нужны для повседневных задач: вовремя проверить упаковки, увидеть остаток, прочитать интерфейс и не потерять локальные записи. Все доступные элементы меняют поведение приложения и сохраняются вместе с данными.

| Раздел | Параметр | Значение по умолчанию и действие |
|---|---|---|
| Внешний вид | Тема | Системная; также светлая и тёмная |
| Внешний вид | Размер текста | Обычный; увеличение на 15% или 30% поверх системного масштаба |
| Содержимое | Аптечка при запуске | Последняя открытая; можно закрепить конкретную аптечку |
| Содержимое | Сортировка | По названию; альтернатива — по ближайшей дате среди упаковок препарата, неизвестные даты в конце |
| Содержимое | Порог срока | 30 дней; варианты 7, 14, 30, 60, 90. Единый порог для списка, фильтра, карточек, сводки и счётчиков |
| Предупреждения | Сроки | Включены; сводка в «Приёме» показывает истекающие, истёкшие и неизвестные сроки упаковок с ненулевым остатком |
| Предупреждения | Малый остаток | Включён; по умолчанию 2 единицы или меньше в конкретной упаковке, включая нулевой остаток |
| Предупреждения | Порог остатка | 1, 2, 3, 5 или 10 единиц. Единицы берутся из записи: таблетки, флаконы и т. д.; это не прогноз дней лечения |
| Приём | Показывать расписание | Включено; общая пауза скрывает расписание, сохраняя записи и историю |
| Приём | Отдельные расписания | Можно включать и выключать каждое, видны время, доза и аптечка |
| Данные | Создать копию | Полный JSON через копирование или выделение текста; все аптечки, упаковки, расписания, история и настройки |
| Данные | Восстановить копию | Проверка формата, версии, идентификаторов и связей; затем подтверждение полной замены с числом записей |
| Данные | Сбросить настройки | Подтверждение; записи и переключатели отдельных расписаний сохраняются |
| Данные | Удалить все записи | Подтверждение; удаляются упаковки, расписания и история всех аптечек. Названия аптечек и настройки остаются |
| О приложении | Версия и возможности | Локальный прототип, ограничения синхронизации и назначение приложения |

## Самые важные решения

1. Порог срока относится к предупреждению, а не меняет дату годности. Ближайшая дата учитывает внесённый срок после вскрытия. Выключение сводки не скрывает статусы в карточках.
2. Предупреждения охватывают все локальные аптечки. Расписание не удаляется при паузе; факт приёма не появляется автоматически.
3. Размер текста дополняет системные настройки доступности. Фильтры переносятся на строки, весь экран списка прокручивается; тёмная тема использует семантические пары цветов.
4. Резервная копия особенно важна, пока нет сервера. Пользователь видит, что копия не зашифрована и очистка данных приложения/браузера удаляет локальные записи. При ошибке чтения или отмене данные не заменяются.
5. Значения по умолчанию работают сразу; не требуется заполнять профиль или регистрироваться.

## После подключения соответствующих сервисов

Эти пункты описаны в информации о прототипе, без неработающих кнопок:

- Системные уведомления: разрешение ОС, напоминания о приёме, ежедневная проверка срока/остатка, время сводки, звук и режим тишины для сводки. Время приёма задаётся отдельно в расписании и не должно незаметно переноситься режимом тишины.
- Аккаунт и синхронизация: вход, состояние синхронизации, последняя успешная копия, восстановление на другом устройстве, выход, удаление аккаунта.
- Семейный доступ: приглашения в конкретную аптечку, роли участников и отзыв доступа. Отдельные настройки видимости личных расписаний и истории.
- Конфиденциальность: блокировка приложения средствами устройства и безопасные облачные копии после выбора архитектуры хранения.

Текущая версия не запрашивает системные разрешения для функций, которых ещё нет. Язык интерфейса — русский; смена языка потребует полноценного перевода всех экранов.

## Аккаунт

В начале настроек добавлена ссылка на аккаунт с именем текущего демо-профиля либо предложением проверить вход. Настройки, резервная копия и сброс работают в области текущего профиля. Управление способами входа, импортом гостевых аптечек, выходом и удалением находится на отдельном экране; будущие устройства, синхронизация и приватность описаны в [accounts.md](accounts.md).
