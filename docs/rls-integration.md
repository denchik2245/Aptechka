# Подключение фотографий РЛС Аврора

## Результат живой проверки

2 октября 2026 года проверены официальные примеры `inventory_brief?packing_id=95500` и `inventory_complete?packing_id=124800` по HTTPS с опубликованным в документации заголовком демо-авторизации. Оба ответа — **HTTP 401 Unauthorized**. Данные и фотографии не получены. Встроенный манифест фотографий пока пуст; интерфейс не выдаёт фикстуры или чужие картинки за РЛС.

[Документация подключения](https://aurora.rlsnet.ru/14/page3.html) описывает демонстрационный доступ только к позициям с `packing_id`, кратным 100. Даже работающий демо-доступ не обеспечивает фотографии всех лекарств. Для персонального тестового доступа поставщик предлагает заявку на демоверсию. Контакт: `sales@rls-aurora.ru`.

## Что подготовлено

`tools/import_rls_photos.py` — клиент и импортёр фотографий. Логин и пароль читаются из переменных окружения `RLS_USERNAME` и `RLS_PASSWORD`, никогда не входят в Flutter assets или код клиента. Учётные данные и тела ошибочных ответов не выводятся. Используется только официальный HTTPS-домен; перенаправления с авторизацией запрещены.

Импортёр поддерживает проверку доступа, загрузку выбранных GTIN из публичного справочника МДЛП и обработку разрешённого экспорта `inventory_brief` в JSON. Для сопоставления используются точные штрихкоды из ответа, не название или первая найденная картинка. Несколько различных изображений для одного GTIN считаются неоднозначным совпадением и пропускаются. В ответах нескольких совпавших GTIN одно изображение скачивается один раз.

Запросы выполняются последовательно с интервалом не менее секунды. При 401/403, ошибках формата, пустом ответе, HTML вместо изображения или отсутствии точных совпадений прежний манифест не заменяется. Изображения получают имена по SHA-256, а манифест публикуется после успешной загрузки и проверки всех выбранных файлов. Неиспользуемые старые изображения автоматически не удаляются.

Flutter показывает фото после выбора варианта в форме и в карточке сохранённой упаковки. Сохранённый `catalogEntryId` связывает выбранный вариант с GTIN каталога, не приписывая пользователю отсканированный код. Изменение характеристик выбранного варианта скрывает его фото. При отсутствии фотографии интерфейс сохраняет обычный вид; при ошибке файла показывает сообщение. Фото сохраняет пропорции, содержит подпись источника, а импорт из демо явно обозначен тестовым.

Фотографии доставляются как assets приложения, поэтому пользовательские аптечки, аккаунты и поисковые запросы не отправляются РЛС. Для первых проверок подходит импорт нескольких GTIN. Для массового импорта можно использовать JSON-экспорт номенклатуры, полученный у поставщика, и разрешение на фотографии.

## Проверка после получения доступа

Задать `RLS_USERNAME` и `RLS_PASSWORD` в окружении терминала или секретах процесса. Не добавлять их в репозиторий и не указывать реальные пароли в командах, попадающих в историю.

Из корня проекта:

```bash
python3 tools/import_rls_photos.py --probe
```

Проверка возвращает факт подключения, число записей и записей со ссылками на фото, не меняя assets. При отказе доступа завершается с ошибкой, а не переключается на фиктивный успех.

Импорт конкретного публичного GTIN для локального тестирования:

```bash
python3 tools/import_rls_photos.py --gtin 04601669000675 --usage demo
```

Указанный GTIN есть в МДЛП; доступность его фотографии в демо ещё не подтверждена. Несколько упаковок задаются повторением `--gtin`. Если ответа по 14-значному коду нет и он начинается с нуля, проверяется соответствующий 13-значный EAN. Итог всё равно проверяется по возвращённому штрихкоду.

Для согласованной поставки:

```bash
python3 tools/import_rls_photos.py --inventory /path/to/authorised-inventory.json \
  --usage licensed --rights-reference 'Номер договора или разрешения'
```

`rights-reference` фиксирует основание использования, но не заменяет разрешение правообладателя. Режим `demo` предназначен для локальной оценки. Перед распространением фотографий согласовать отображение в потребительском приложении и хранение/распространение копий. Заявки, договоры и покупки в этом изменении не выполнялись.

После успешного импорта пересобрать приложение:

```bash
flutter build web --release
```

Каталог МДЛП остаётся самостоятельным источником характеристик. Сбой РЛС не прерывает поиск и ручное добавление препарата.
