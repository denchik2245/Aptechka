# Дизайн-система «Аптечки»

## Принципы

- Спокойный, доверительный интерфейс без визуальных признаков постановки диагноза.
- Один основной призыв к действию на экран.
- Цвет статуса всегда сопровождается текстом и пиктограммой.
- Интерактивная область не меньше 48 dp на Android и 44 pt на iOS.
- Отступы построены на сетке 4/8 dp.
- Интерфейс поддерживает системную светлую и тёмную тему.
- На телефоне используется нижняя навигация, на широком экране — NavigationRail.

## Семантические цвета

| Токен | Светлая тема | Назначение |
|---|---:|---|
| Primary | `#2F6F5E` | Основные действия и выбранная навигация |
| Primary dark | `#1E4E41` | Сводная карточка |
| Canvas | `#F5F5F1` | Фон приложения |
| Ink | `#18201D` | Основной текст |
| Muted | `#5D6A65` | Вторичный текст |
| Warning | `#A65F16` | Срок скоро истекает |
| Danger | `#B13C3C` | Препарат просрочен |
| Success | `#247A57` | Срок в порядке, приём отмечен |

Тёмная тема строится из Material ColorScheme и отдельных поверхностей `#121B18` и `#1A2521`. Статусные цвета не инвертируются.

## Компоненты

- Радиус карточек: 20–24 dp.
- Радиус полей и кнопок: 16 dp.
- Основная кнопка: минимум 52 dp по высоте.
- Поля имеют постоянную видимую подпись, а ошибки показываются рядом с полем.
- Для длинных списков используется ленивый `ListView`.
- Текст масштабируется системными средствами; фиксированная высота для текстовых карточек не применяется.

## Навигация

Четыре верхнеуровневых раздела:

1. Аптечки.
2. Содержимое.
3. Приём.
4. Настройки.

Создание, сканирование и карточка препарата открываются поверх основной оболочки и имеют предсказуемую кнопку «Назад».
