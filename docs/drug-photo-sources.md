# Источники фотографий препаратов

Проверено 2 октября 2026 года. Фотографии ещё не получены; для РЛС подготовлены импортёр и показ фото в приложении. Живая проверка опубликованного демо-доступа вернула HTTP 401. Подробности — в [rls-integration.md](rls-integration.md). Заявки поставщикам не отправлялись.

В подключённой открытой выгрузке МДЛП отсутствуют поля с фотографиями и URL изображений. Дополнительный каталог фотографий можно связывать с её записями через штрихкоды. Публичная документация коммерческого API не означает свободную лицензию на изображения.

## Кандидаты

### РЛС Аврора

[Описание сервиса](https://aurora.rlsnet.ru/), [Web API](https://aurora.rlsnet.ru/Help), [описание базы](https://aurora.rlsnet.ru/14/page3.html).

На главной странице опубликована статистика на 02.10.2026: **25 877 изображений упаковок** и **203 371 код EAN**. Это показатели всего справочника, а не число совпадений с нашим набором МДЛП. Сервис предоставляет изображения, штрихкоды, номенклатуру и коды ЕСКЛП.

Связь: номенклатура содержит `barcode` и `picname`; метод `inventory_pics?picname=...` возвращает фотографию, вариант без параметров — архив фотографий. Документация описывает поиск номенклатуры по EAN, полную выгрузку и обновления по `OnDate`.

Коммерческая подписка с тестовым доступом по запросу. Нужно согласовать отображение фотографий в публичном приложении для пользователей, разрешение на собственное хранение и кеширование, обновления, прекращение использования после окончания договора. Опубликованное назначение сервиса — интеграция в МИС; применимость договора к нашей «Аптечке» должна быть подтверждена поставщиком. Контакт из сайта: `sales@rls-aurora.ru`.

Вывод: первый кандидат для теста благодаря документированной связи штрихкода и изображения. Покрытие нашей базы пока не проверено.

### Видаль

[База для разработчиков](https://www.vidal.ru/services/bd-vidal), [REST API](https://www.vidal.ru/api).

Поставщик заявляет **около 2 500 фотографий упаковок**, одобренных компаниями в течение календарного года. Доступны поставка базы в MS Access и API. Формулировка «открытый формат» относится к формату поставки, не к свободной лицензии.

REST API документирует JSON, авторизацию и поиск `product/list?filter[barCode]=...`. Для фото нужно получить тестовую выдачу, проверить связь с конкретной упаковкой и действующие условия поставки. Тестовый доступ предлагается по запросу; контакт: `m.vlasenko@vidal.ru`.

Вывод: коммерческий кандидат с меньшим заявленным числом фото; может дополнять другой источник. Размер пересечения каталогов не установлен.

### Фарм-Портал / PharmPortal PIM

[Для разработчиков](https://pro.pharm-portal.ru/for/developers), [API-интеграция](https://pro.pharm-portal.ru/api-integration), [документация API](https://api.pharm-portal.ru/docs).

Страницы проверены также в браузере: текст некоторых страниц недоступен без JavaScript. Поставщик заявляет фотографии упаковок непосредственно от производителей через PIM, передачу данных через API и отдельные сведения о штрихкодах упаковок.

Доступ по `access_token`, который выдаётся после обращения с данными компании. Число доступных фото, цены, точная связь изображений с GTIN, права на использование в потребительском приложении и кеширование на просмотренных страницах не установлены. Это вопросы для тестового доступа и договора. Контакт: `info@pharm-portal.ru`.

Вывод: перспективный основной или дополнительный источник изображений от производителей; требуется проверка полноты и условий.

### Wikimedia Commons

[Условия повторного использования](https://commons.wikimedia.org/wiki/Commons:Reusing_content_outside_Wikimedia/en), [пример фото «Цитрамона» под CC0](https://commons.wikimedia.org/wiki/File:%D0%A6%D0%B8%D1%82%D1%80%D0%B0%D0%BC%D0%BE%D0%BD.jpg), [категория ибупрофена](https://commons.wikimedia.org/wiki/Category:Ibuprofen).

Бесплатный источник отдельных изображений. У каждого файла своя лицензия; для CC BY и CC BY-SA нужно соблюдать требования к авторству и лицензии, для изменённых CC BY-SA изображений — условия распространения производного изображения. Лицензия конкретного фото проверяется по его странице, а не по лицензии текста Wikipedia.

Это не готовый справочник российских упаковок с GTIN. Фото может показывать таблетки, зарубежную упаковку или устаревший дизайн. Найденный пример «Цитрамона» не привязан к GTIN и не подходит для автоматического присвоения всем вариантам препарата. Нужна ручная проверка соответствия конкретной записи.

Вывод: подходит для небольшого набора проверенных изображений в прототипе; полноту для лекарств РФ не подтверждает.

## Выбор и объединение

Рекомендация: проверить РЛС и Фарм-Портал на одинаковом наборе наших GTIN, затем оценить, сколько дополнительных точных изображений даёт Видаль. Подключать несколько платных источников имеет смысл после оценки пересечения и цены. Для прототипа без договора можно использовать отдельные вручную проверенные фотографии со свободной лицензией.

У поставщика нужно запросить тестовую выборку для примерно 100–200 GTIN с разными производителями, формами и упаковками. Сравнить долю точных совпадений, актуальность дизайна, качество фото, цену и условия использования. Показатели каталогов выше не складываются: фотографии могут совпадать или обслуживать несколько номенклатурных позиций.

Предлагаемая техническая схема для будущего подключения:

- точный GTIN сопоставляется с вариантом упаковки; 13-значный EAN можно привести к 14-значному GTIN добавлением ведущего нуля, без удаления остальных значимых цифр;
- сохраняются источник, внешний идентификатор, ссылка на оригинал, лицензия или основание договора, авторство при необходимости и дата проверки;
- при нескольких точных изображениях выбирается подтверждённое актуальное фото; совпадение только названия не считается точным;
- при отсутствии точного совпадения остаётся иконка и возможность добавить собственное фото;
- ключи коммерческих API хранятся на сервере, а не в Flutter-клиенте; предварительный импорт публичного каталога позволяет не отправлять поставщику пользовательские аптечки и поисковые запросы;
- хранение и выдача изображений из нашего хранилища выполняются только в пределах лицензии или договора.

Готовую свободную массовую базу фотографий с подтверждённым полным покрытием наших 74 791 GTIN в ходе поиска не удалось установить. Автоматическое копирование фото с сайтов аптек не рассматривалось как разрешённая интеграция без соответствующих условий или разрешения.
