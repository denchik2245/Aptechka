# Архитектура

Проект организован по функциям и разделён на слои:

```text
lib/
  app/                    конфигурация приложения и маршруты
  core/                   тема, форматирование и общие виджеты
  features/
    home/presentation/
    inventory/
      application/        контроллер сценариев
      data/               локальное хранилище и каталог
      domain/             состояние приложения
      presentation/       экраны и компоненты
    medicines/domain/     модель препарата
    reminders/            расписание и журнал приёма
    scanner/              сканирование и разбор GTIN
    settings/
    shell/                адаптивная навигация
```

## Поток данных

```text
Экран → AppController → MedicineRepository → SharedPreferences
                  ↓
           неизменяемый AppState
```

`MedicineRepository` является интерфейсом. Локальное JSON-хранилище подходит для MVP; его можно заменить SQLite/Drift или синхронизируемым репозиторием без изменения экранов.

`DrugCatalogService` также отделён интерфейсом. Сейчас используется небольшой демонстрационный справочник. Следующая реализация будет выполнять поиск `GTIN → МДЛП/ГРЛС` через собственный backend.

## Границы первой версии

Реализовано:

- локальный учёт упаковок;
- вычисление статуса срока годности;
- Data Matrix/EAN-сканер и выделение GTIN;
- ручное добавление;
- расписание и журнал факта приёма;
- адаптивный интерфейс и тёмная тема.

Следующими отдельными модулями подключаются:

- системные локальные уведомления;
- импорт открытой выгрузки МДЛП и API поиска GTIN;
- SQLite/Drift для больших объёмов;
- облачная синхронизация и семейный доступ;
- OCR срока годности.
