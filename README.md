# Аптечка

Интерактивный Flutter-прототип будущего приложения для учёта домашних лекарств. Проект создаётся для Android и iOS; Web используется как быстрый предпросмотр интерфейса. Подготовлена отдельная development-основа аккаунтов; публичного сервиса пока нет.

## Что можно пройти в прототипе

- выбор личной или демонстрационной общей аптечки;
- список препаратов с группировкой физических упаковок, поиском и фильтрами;
- просмотр количества, места, общего срока и срока после вскрытия каждой упаковки;
- явные статусы «срок не истёк», «срок скоро истечёт», «срок истёк» и «данных недостаточно»;
- добавление и исправление упаковки вручную;
- поиск по названию, МНН и производителю в полной открытой выгрузке МДЛП (74 791 GTIN), выбор варианта с автозаполнением;
- подготовленный импорт фотографий РЛС Аврора и показ по точному GTIN; живой демо-доступ пока возвращает 401, фотографии не загружены ([подключение](docs/rls-integration.md));
- сканирование Data Matrix, EAN-13 и EAN-8;
- выделение GTIN из российского кода маркировки;
- локальное сохранение данных и чтение записей прежней версии прототипа;
- расписание и отметка факта приёма;
- системная, светлая и тёмная тема, увеличение текста и адаптивная навигация;
- настройки порога срока, сортировки и стартовой аптечки;
- локальная сводка сроков и малого остатка в разделе «Приём»;
- общая пауза расписания и переключатели отдельных записей без удаления истории;
- резервная копия JSON, проверка и восстановление, сброс настроек и удаление записей с подтверждением;
- локальные демо-профили, сценарии входа через Яндекс и почту, привязка второго способа;
- отдельные аптечки и настройки каждого профиля, выборочное копирование гостевых записей без дубликатов;
- выход и удаление демо-профиля с подтверждением.

При первом запуске показываются демонстрационные гостевые записи. Настоящая авторизация, совместный доступ между устройствами, облачная копия и системные уведомления ещё не подключены. Демонстрационная «Аптечка мамы» не синхронизируется с другим человеком. Приложение не ставит диагноз и не назначает лечение; статус срока рассчитывается только по внесённым датам.

## Запуск на Windows

В текущей рабочей копии Flutter SDK находится в `.tooling/flutter` и не включается в Git:

```powershell
.\.tooling\flutter\bin\flutter.bat pub get
.\.tooling\flutter\bin\flutter.bat run -d chrome
```

Для Android установите Android Studio, Android SDK и создайте эмулятор, затем:

```powershell
.\.tooling\flutter\bin\flutter.bat devices
.\.tooling\flutter\bin\flutter.bat run -d <device-id>
```

## Запуск на macOS

Установите Flutter и Xcode, откройте репозиторий и выполните:

```bash
flutter pub get
flutter run -d ios
```

Для физического iPhone потребуется выбрать команду разработки в Xcode в настройках Signing & Capabilities.
